# Andrew Blumson game downloads

Official Mac beta installers are attached to this repository’s versioned GitHub Releases. The source for the small download website is maintained here; the game source stays in separate private repositories.

Public download pages: https://downloads.andrewblumson.com/

Each release uses a game-specific tag, installer name, release notes and SHA-256 checksum. Released installer bytes are not replaced silently: a new build gets a new versioned release.

Installers are free to download and play. Publication here does not grant an open-source licence to game code, artwork or bundled assets. Third-party components retain their respective licences and notices.
